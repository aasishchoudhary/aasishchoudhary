# Project GOLD

## Status
**Research / Experimental**

Project GOLD explores a persistent cognitive architecture for AI systems.

It is a research and engineering program, not a claim of artificial consciousness or human-equivalent cognition.

## Core question
How can an AI system maintain useful persistent state while keeping perception, specialist processing, integration, memory, valuation and observability explicit?

## Architecture
~~~text
Environment
     ↓
Perception
     ↓
Specialist Processing
     ↓
Integration / Global State
     ↕
Persistent Core State
 ├── Memory
 ├── Self / World Model
 └── Valuation
~~~

## Engineering principles
- deterministic foundations where possible
- explicit state
- provenance
- telemetry
- modular specialists
- reproducible experiments
- measurable interfaces
- separation between model output and system truth

## Evidence policy
~~~text
Hypothesis
   ↓
Specification
   ↓
Implementation
   ↓
Fixture / Experiment
   ↓
Telemetry
   ↓
Result
   ↓
Interpretation
~~~

No experiment should be described as validated until the underlying evidence exists.

## Planned evidence
- architecture specifications
- canonical schemas
- deterministic feature pipelines
- replayable experiments
- evaluation reports
- failure analysis
- reproducibility records

## Limitations
The project does not establish consciousness, sentience, subjective experience or human-level cognition. Those are separate scientific questions.

The engineering objective is to build and measure useful computational architectures.
