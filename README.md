# Aasish Choudhary

**AI systems · Python · AWS · software engineering**

I build software systems and experimental AI infrastructure.

My current work spans AI agents, cognitive architectures, automation,
cloud services, data pipelines, and developer tooling.

I’m interested in the engineering behind AI systems — how they are
structured, how state and information move through them, how they can
be observed, tested, and improved.

## Selected work

### Project Gold

Research and engineering work around a persistent cognitive architecture
for AI systems.

The architecture explores persistent state, memory, specialist
processing, global state integration, event-driven communication,
telemetry, provenance, and agent orchestration.

### Secret Build Agent

An evidence-first workflow for AI-assisted software development and
execution.

The project focuses on keeping experiments traceable, separating
planning from execution, and making system state and results observable.

### AWS / Serverless

Hands-on work with AWS Lambda, S3, APIs, and serverless application
deployment.

The focus is on understanding the complete path from an application
idea to a deployed service.

### SAR Ground Control UI

A software-only interface concept for search-and-rescue operations,
focused on mission visualization, telemetry presentation, sensor
dashboards, and operator workflows.

This is a UI/simulation project and does not implement real flight
control.
