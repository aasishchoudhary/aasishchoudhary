# Security Policy

## Reporting a vulnerability

Please do not publish credentials, tokens, private data or exploitable security details in a public issue.

For a suspected security problem, contact the repository owner privately through the contact method available on the GitHub profile.

## Repository rules

- Never commit API keys, passwords or access tokens.
- Use environment variables or secret-management mechanisms for credentials.
- Remove sensitive data from logs and screenshots.
- Treat external input as untrusted.
- Keep permissions as small as practical.
- Do not expose private client or experimental data.

## Portfolio rule

Public documentation should demonstrate engineering quality without exposing confidential information.
