# Contributing

This repository is primarily a professional profile and portfolio.

Suggestions are welcome when they improve:

- technical clarity
- documentation
- reproducibility
- accessibility
- security
- portfolio quality

## Preferred contribution style

Explain:

**Problem → Proposed change → Evidence → Trade-offs**

Avoid changes that add visual complexity without improving clarity or useful information.

## Quality bar

Before proposing a change, check:

- links work
- Markdown renders correctly
- claims are accurate
- examples are reproducible where applicable
- no secrets or private information are included
